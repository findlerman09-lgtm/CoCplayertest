# Clara Whitcombe dossier routes

This directory exists to make the player-facing dossier multi-level rather than one long page. The route structure is:

- `/characters/clara-whitcombe/` — Overview
- `/characters/clara-whitcombe/sheet/` — Character Sheet
- `/characters/clara-whitcombe/people/` — People
- `/characters/clara-whitcombe/correspondence/` — Correspondence
- `/characters/clara-whitcombe/documents/` — Personal Documents
- `/characters/clara-whitcombe/possessions/` — Possessions & Means

The Markdown source remains deliberately lightweight; shared framing and navigation live in `_layouts/base.html` and `assets/architecture.css`.
